# HatırlaBeni - User Stories

## Amaç

Bu doküman, HatırlaBeni projesinin kullanıcı ihtiyaçlarını tanımlayan User Story'leri içermektedir. User Story'ler, kullanıcıların sistemden beklentilerini ifade eder ve geliştirme sürecinde Product Backlog'un temelini oluşturur.
